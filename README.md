# Novo layout Lunex (demonstração)

Exemplo do fluxo pré-sell → P1 com o quiz no estilo Roblox, para publicar no GitHub Pages.

| Página | Arquivo | Origem |
| --- | --- | --- |
| Pré-sell | `index.html` | games.lunexflash.com/create-games-earn-robux-develop-skills/ |
| P1 com overlay | `p1/index.html` | games.mirveto.com/build-experiences-grow-an-audience-expand-your-robux-potential-p1/ |

## O que mudou

- **Pré-sell:** nova pergunta ("What type of Roblox games do you enjoy most?") no layout Roblox. O fundo borrado é o mesmo da página original.
- **P1:** o overlay do Cronos foi trocado por um overlay no mesmo estilo, com as mesmas telas e textos do quiz atual. O texto da página por trás é o original.

## O que foi tirado só da demonstração

Para não gerar dados falsos nem anúncios fora do domínio, as páginas desta demo não carregam:
Spun Ads, Rebid, GTM, Pushia, analytics da Spun, Cloudflare Insights, o tracking para a planilha, a divisão de tráfego e o Cronos.

Em produção, a pré-sell continua compatível com o script original: as classes `.card`, `.opt`, `.opt-text`, `data-answer` e `.selected` foram mantidas.
